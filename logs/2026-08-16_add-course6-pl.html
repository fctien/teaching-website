3. 過程中的問題與修復

問題：PL_DRIVE_FOLDER const 宣告順序錯誤
resourceData 中引用了 PL_DRIVE_FOLDER，但該 const 在 resourceData 之後才宣告，觸發 ReferenceError: Cannot access 'PL_DRIVE_FOLDER' before initialization。
修復：移除 PL_DRIVE_FOLDER const，改為在所有引用處直接內嵌 Google Drive URL 字串。
問題：瀏覽器快取頑固保留舊版 JS
修復後瀏覽器 console 仍顯示舊錯誤，即使重啟 dev server 也未清除。
驗證方式：透過 fetch('/js/data.js?nocache=...') 確認伺服器端檔案已正確更新（hasPL: false）。頁面重新載入後所有功能正常運作。
